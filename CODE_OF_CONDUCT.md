# Code of conduct

This project follows the [Ruby Code of Conduct](https://www.ruby-lang.org/en/conduct/).

## Conduct

- Participants will be tolerant of opposing views.
- Participants must ensure that their language and actions are free of personal attacks and disparaging personal remarks.
- When interpreting the words and actions of others, participants should always assume good intentions.
- Behaviour which can be reasonably considered harassment will not be tolerated.

## Enforcement

Report unacceptable behaviour to [conduct@tideswellgroup.com](mailto:conduct@tideswellgroup.com). Reports are reviewed promptly and fairly, and your privacy is respected.

Don't use the issue tracker for this. Issues here are public and GitHub has no confidential option, so a report filed there is visible to everyone.

If the report concerns the maintainer, or you'd rather not raise it with him, GitHub's [report abuse](https://github.com/contact/report-abuse) form goes to GitHub rather than to this project.
